What it does

A focused layer between your form and its submit.

Choose the forms to validate, add the expected wrapper class to each field, and let the library report invalid values.

01

Field-level feedback

Invalid wrapped fields receive a message or an outline, based on your configuration.

02

Useful defaults

Default messages cover the input types supported by the current 2.0.0 implementation.

03

Your own wording

Override individual messages with the errorMessages option while keeping the rest.

Quick start

Get a form ready in three steps.

The library checks the first input, select, or textarea inside each .jn-input-wrap when the form is submitted.

  1. Include the libraryUse the downloaded files or the project CDN links.
  2. Mark the form and fieldsGive the form a selector and wrap each field in .jn-input-wrap.
  3. Initialize onceCreate JnFormValidation with your form selector.
See the full installation guide →
HTML + JavaScript
<link rel="stylesheet" href="assets/css/jn-formvalidation.min.css">

<form class="signup-form" action="/signup" method="post" novalidate>
  <div class="jn-input-wrap">
    <label for="email">Email</label>
    <input id="email" name="email" type="email">
  </div>
  <button type="submit">Continue</button>
</form>

<script src="assets/js/jn.formvalidation.min.js"></script>
<script>
  new JnFormValidation({
    formClass: ".signup-form",
    showErrorMessages: true
  });
</script>
Try it

See the submit-time feedback.

Submit with an empty name or an invalid email to see the library’s field messages. A valid example is directed to a blank local frame and does not send data to an application endpoint.
