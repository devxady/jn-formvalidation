Live preview

Try a blank name, an invalid email, or a phone number that is not exactly ten digits. The library checks each field when you submit. The valid form targets a blank local frame, so it does not send values to an application endpoint.

The corresponding initialization

The live form uses the distributed validator. Its messages are generated by the library; the site only adds alert semantics for this preview.

JavaScript
new JnFormValidation({
  formClass: ".jnForm",
  showErrorMessages: true
});

Supported input types

The validator selects one control inside each .jn-input-wrap. The check depends on the control type; it is not a general schema or constraint engine.

Control typeImplemented check
text, password, search, select, textareaTrimmed value is not empty.
emailBasic pattern requires text before and after @ and a dot-separated suffix.
telExactly ten digits.
numberDigits only; decimals and negative signs are not accepted by this check.
urlBasic pattern accepts URLs beginning with ftp://, http://, or https://.
checkbox, radioAt least one control with the same name in the form must be checked.
fileRequires a selected PNG, JPEG, GIF, or PDF MIME type.
date, time, datetime-local, month, week, range, colorChecks only that the value is not empty; it has no date bounds or range configuration.

Other input types are not checked by the current switch statement. A field must also be inside a .jn-input-wrap.

For a larger live form that includes select, file, checkbox, radio, and date-like controls, open the field-type gallery.

Markup requirements

Use one wrapper per field, or one wrapper for a checkbox/radio group with shared names. Labels in your application should associate with their controls; the library does not add labels or field IDs.

HTML
<link rel="stylesheet" href="assets/css/jn-formvalidation.min.css">

<form class="sample-form" action="/submit" method="post" novalidate>
  <div class="jn-input-wrap">
    <label for="sample-email">Email</label>
    <input id="sample-email" name="email" type="email">
  </div>
  <button type="submit">Submit</button>
</form>

<script src="assets/js/jn.formvalidation.min.js"></script>
<script>
  new JnFormValidation({ formClass: ".sample-form" });
</script>
Not live validation: the current code attaches a submit listener only. A message remains until another submit attempt clears and recreates messages.
